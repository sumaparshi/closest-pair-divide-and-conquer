# Closest Pair of Points — Algorithm Analysis 📐
Comparison of Brute Force and Divide & Conquer algorithms
for finding the closest pair of points, with full 
performance benchmarking.

## What it does
- Implements both Brute Force O(n²) and 
  Divide & Conquer O(n log n) algorithms
- Benchmarks performance across input sizes 
  from 10,000 to 100,000 points
- Verifies both algorithms return identical results
- Plots runtime comparison graph

## Results
- Divide & Conquer consistently outperforms Brute Force
- 10x+ speed gain confirmed at 100,000 points
- Average times computed over 10 iterations per input size

## Tech Stack
Python, Matplotlib, Math, Random, Time
